# Project 3 Seminar Implementation Plan

> Execute inline with superpowers:executing-plans, test first.

**Goal:** Deliver candidate-linked dual-view seminar review with grounded visual observations.
**Architecture:** Separate seminar router/store/service reuse the existing media probe and Whisper. An isolated vision adapter sends bounded frame sequences; React controls two players on one canonical time axis.
**Tech Stack:** FastAPI, Python, PyAV/Pillow, OpenAI-compatible vision, Next.js/React/TypeScript.
**Spec:** docs/superpowers/specs/2026-11-16-seminar.md

## Global Constraints
- Preserve P1/P2; no real credentials or media committed.
- screen_time = speaker_time + offset_ms; derived evidence times, never model-authored times.
- Missing screen audio allowed; all AI observations remain reviewable.
- Local course-demo single-process deployment, not new authentication infrastructure.

## Review Focus
- Positive/negative offsets and non-overlapping recordings: reject invalid ranges.
- Missing audio/vision configuration: explicit warning/error and preserved artifacts.
- Invented or cross-window frame IDs: reject unsupported observations.
- Repeated analyze/upload/alignment mutations: lock active jobs and avoid stale evidence.
- Seeking/buffering/end-of-overlap: pause both views rather than show mismatched evidence.
