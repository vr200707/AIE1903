# Project 3 seminar analysis

Approved direction: extend the existing recruitment helper with candidate-linked seminar review, using synchronized speaker/screen recordings, sampled image sequences, and evidence-grounded visual comments. Preserve P1/P2.

Use speaker time as canonical: screen_time = speaker_time + offset_ms. Analyze only overlapping media. Manual offset confirmation is required. Upload each view in 4 MiB chunks. Persist metadata and review decisions locally. Reuse local Whisper on the selected audio track, mapping screen transcript times back to speaker time. Missing audio degrades with a warning, not a blocked visual scan.

Sample short 8-second windows at 1 fps, skip black images, reduce repeated screen frames while retaining speaker sequences. Save exact frames and timestamps. Use a separately configured OpenAI-compatible vision model; never silently send images to the text-only default. Validate model evidence IDs and derive event bounds from saved frames. Group observations by audience_orientation, gesture_usage, posture_movement. Unclear/occluded actions must be omitted, not invented. No personality, emotion, hiring verdicts or unsupported scores.

UI: candidate/session selection, two uploads, alignment, bounded scan range, transcript/audio choice, progress, dimension cards, saved frame sequences, synchronized evidence replay and persistent review status. Explicit start initiates model calls. Model failure is visible and retryable; local evidence survives.

Alternatives: pose rules and person tracking remain optional future detectors; neither is needed for the first guide-compliant loop.
