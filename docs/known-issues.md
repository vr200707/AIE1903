# 当前已知问题

## 存储

- 上传记录和档案保存在进程内字典中。
- 进程重启后，档案索引会丢失。
- 本地文件缓存不能替代生产数据库。

## 性能

- `/api/analyze` 是同步请求。
- 多篇论文、网页搜索和 OCR 会显著增加响应时间。
- 目前没有任务队列、进度回传或取消机制。

## 外部依赖

- OCR 依赖 Tesseract、语言包和 Poppler。
- 未安装 OCR 环境时，相关测试会跳过。
- Crossref、OpenAlex 和网页搜索均依赖网络。
- Bing HTML 解析可能因页面结构变化或限流失效。

## 契约一致性

- `frontend/lib/types.ts` 仍由手工维护，可能与
  `contracts/schema.json` 出现短期漂移。
- FastAPI 业务错误返回嵌套 `detail` 对象；前端做了兼容，但契约仍可进一步统一。

## 部署

- 当前没有生产数据库、鉴权、任务隔离或持久化迁移方案。
- 跨机器使用前端代理时需要配置 `NEXT_PUBLIC_API_BASE`。
