## 检查方法

- 执行 `python -m tools.check_sample_documents`。
- PDF 使用 `pypdf` 读取页数和文本层。
- DOCX 使用 `python-docx` 读取段落、表格和文本。
- 每个文件重新计算大小与 SHA-256，并与 `manifest.csv` 比较。
- 固定开发依赖为 `pypdf==6.19.0`、`python-docx==1.2.0`。

## 使用边界

- 这套文件仅用于解析器、读取顺序、分页、多语言和 OCR 边界测试。
- 它不能替代团队提供的真实脱敏样本，也不能用于证明真实候选人事实。
- 合成二进制文件仍在 Git 忽略目录中，不提交到公开仓库。
- 正式 D3 用例仍需等待团队真实样本和沈一的抽取结果样例。
